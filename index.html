Hero Defense

영웅 디펜스 (가칭) · 팀원 테스트 빌드 · Windows
설치 파일 내려받기 (v0.1.1)
2026-11-16 · 설치하면 바탕화면에 런처가 생겨요. 다음 버전부터는 런처가 알아서 업데이트해요.
Windows 경고(PC 보호)가 뜨면 "추가 정보 → 실행" · 관리자 권한 필요 없음

이번 빌드

  • 설치 파일 + 런처: 다음 버전부터는 런처가 알아서 업데이트해요
  • 맵 새 단장: 흙길 · 숲 · 돌바닥 · 소나무 · 성벽 · 성문 · 수정 성소를 타이틀 그림과 같은 화풍으로
  • 타이틀 화면 새 그림
  • 영웅 체력은 머리 위에 (30% 아래면 깜빡이고 화면 가장자리가 붉어짐)
  • 15분 한 판 · 30웨이브 · 웨이브마다 고블린 무리 · 30웨이브 대장을 잡으면 승리 (혼자 하기만)
  • 시험용 키: N 다음 웨이브, L 레벨 업

조작

WASD / 방향키이동 (공격은 자동)
Q E R스킬 (Q는 2레벨, E는 5레벨, R은 7레벨 전직 뒤)
Z X C영웅 선택 · 전직 선택 · 상점 구매 (상점 근처)
Esc타이틀로 나가기
시험용N 다음 웨이브로 건너뛰기 · L 레벨 업

봐 주세요

  • 고블린 무리가 몰려올 때 손맛 (너무 쉬움 / 적당 / 버거움)
  • 몇 웨이브까지 버텼는지, 언제 전직했는지
  • 헷갈렸던 화면 · 조작, 버그 (언제, 무엇을 하다가)
