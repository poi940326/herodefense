영웅 디펜스 (가칭) · 팀원 테스트 빌드 · Windows
설치 파일 내려받기 (v0.2.0)
2026-11-18 · 설치하면 바탕화면에 런처가 생겨요. 다음 버전부터는 런처가 알아서 업데이트해요.
Windows 경고(PC 보호)가 뜨면 "추가 정보 → 실행" · 관리자 권한 필요 없음

이번 빌드

  • 새 모드: 타이틀 맨 위 "시작: 사냥 → 보스 (새 영웅)" — 영웅 셋 기사 · 마법사 · 엘프 궁수 중에서 Z / X / C로 골라요
  • 조작: 방향키 이동, Z 공격(연타하면 콤보), X 패링, Space 회피 (기사 구르기 · 마법사 점멸 · 엘프 백덤블링)
  • 스킬: A · S · D · F (레벨 1 · 2 · 4 · 6에 열려요). Tab = 룬 스킬트리 (화살표로 고르고 Z로 찍기, 레벨업마다 점수)
  • 사냥: 몹이 사방에서 우르르 쏟아져요. 몹은 몸으로 막아서 둘러싸이면 갇혀요 — 회피로 뚫고 나가세요
  • 보스 고블린 대장: 노란 공격은 X로 패링 (휘청 → 4번 막으면 그로기), 빨간 공격(돌진)은 피하기
  • 한 판 = 사냥 → 보스 → 휴식, 세 번. 장비는 능력치만 올려줘요
  • 밸런스는 시작값이에요. 너무 어렵거나 쉬운 곳, 어색한 그림이 있으면 알려 주세요
  • 예전 모드(디펜스 · 예전 사냥)는 메뉴 아래 "예전:"으로 남겨 뒀어요

조작

WASD / 방향키이동 (공격은 자동)
Q E R스킬 (Q는 2레벨, E는 5레벨, R은 7레벨 전직 뒤)
Z X C영웅 선택 · 전직 선택 · 상점 구매 (상점 근처)
Esc타이틀로 나가기
시험용N 다음 웨이브로 건너뛰기 · L 레벨 업

봐 주세요

  • 고블린 무리가 몰려올 때 손맛 (너무 쉬움 / 적당 / 버거움)
  • 몇 웨이브까지 버텼는지, 언제 전직했는지
  • 헷갈렸던 화면 · 조작, 버그 (언제, 무엇을 하다가)
